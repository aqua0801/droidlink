First public release of DroidLink, a phone-to-PC companion that pairs an Android phone with a
Windows PC over an end-to-end encrypted connection on your own network. See the
[README](https://github.com/aqua0801/droidlink#readme) for the full feature list.

## Downloads

| File | For |
|---|---|
| `DroidLink-0.1.0-windows-x64.exe` | Windows 10/11 (64-bit) installer. Includes its own Java runtime. |
| `DroidLink-0.1.0.apk` | Android 10 or newer |
| `SHA256SUMS.txt` | Checksums for the files above |

## Getting started

1. Install and start DroidLink on the PC.
2. Install the APK on the phone. Android will ask you to allow installing apps from the
   browser or file manager you used; that is expected for apps outside the Play Store.
3. On the PC, create a pairing QR code; on the phone, tap **Scan QR code**. Both devices need
   to be on the same network (or reachable over e.g. Tailscale).

For ADB enhanced mode (background clipboard, screen control, APK install, logcat), enable USB
debugging or wireless debugging on the phone and have `adb` from the Android SDK
platform-tools on the PC's `PATH`.

## Notes

- **Windows SmartScreen:** the installer is not code-signed, so Windows may show
  "Windows protected your PC". Choose **More info → Run anyway**.
- **Verify downloads:** compare `Get-FileHash <file> -Algorithm SHA256` with `SHA256SUMS.txt`.
- The desktop app is Windows-only for now; global hotkeys, the clipboard watcher and the screen
  mirroring decoder rely on Windows APIs.
- Wireless mirroring is view only; on Android 15+ the system hides sensitive content such as
  one-time codes during capture.
