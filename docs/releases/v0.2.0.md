DroidLink 0.2.0 brings the desktop app to Linux and adds the phone's audio to ADB screen
mirroring. See the [README](https://github.com/aqua0801/droidlink#readme) for the full feature
list.

## What's new

- **Linux desktop app** (x86-64): a `.deb` for Ubuntu 22.04+ / Debian 12+ and a portable
  `.tar.gz` for other distributions. Works on X11 and Wayland sessions, with freedesktop
  notifications, a tray icon where the desktop provides one, global clipboard hotkeys on X11,
  and "show in folder" through your file manager. See the
  [Linux section](https://github.com/aqua0801/droidlink#linux) for what differs between X11
  and Wayland.
- **Phone audio while mirroring over ADB** (Android 11+): the phone's sound plays on the PC,
  with a mute button in the mirror window. Optionally keep it playing on the phone too
  (Android 13+). Both are under **Settings → Screen mirroring**.
- **Troubleshooting** section in the README for pairing and connection timeouts.

## Downloads

| File | For |
|---|---|
| `DroidLink-0.2.0-windows-x64.exe` | Windows 10/11 (64-bit) installer |
| `DroidLink-0.2.0-linux-x64.deb` | Ubuntu 22.04+ / Debian 12+ (64-bit) |
| `DroidLink-0.2.0-linux-x64.tar.gz` | Other Linux distributions: unpack anywhere and run `DroidLink/bin/DroidLink` |
| `DroidLink-0.2.0.apk` | Android 10 or newer |
| `SHA256SUMS.txt` | Checksums for the files above |

The desktop packages include their own Java runtime.

## Upgrading

- **Windows:** run the new installer; it replaces 0.1.0 and keeps your pairing and settings.
- **Android:** install the new APK over the existing app; pairing is kept.
- **Linux (.deb):** `sudo apt install ./DroidLink-0.2.0-linux-x64.deb`

## Notes

- **Linux firewall:** allow incoming TCP on port 47100 (and mDNS, UDP 5353) so the phone can
  connect, e.g. `sudo ufw allow 47100/tcp`.
- **Windows SmartScreen:** the installer is not code-signed, so Windows may show
  "Windows protected your PC". Choose **More info → Run anyway**.
- **Verify downloads:** compare the SHA-256 of each file with `SHA256SUMS.txt`
  (`Get-FileHash <file> -Algorithm SHA256` on Windows, `sha256sum -c --ignore-missing SHA256SUMS.txt` on Linux).
- Audio is forwarded only when mirroring over ADB; wireless mirroring is still view only and
  silent.
